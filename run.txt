1) First way to run example.
* Mounts your current working directory ($PWD) from the host into the container at /app
* This makes your local files (like index.js, copy_schemas.js, package.json, etc.) available inside the container.
* -w /app Sets the working directory inside the container to /app So any relative paths in commands run inside the container will start from /app (your mounted project).
* --env-file .env Loads environment variables from your local .env file and makes them available inside the container.
* node Here, you’re pulling/running the official Node.js image (node:latest by default).
* node index.js copy_schemas.js This is the command that runs inside the container.

docker run --rm \
  -v "$PWD":/app \
  -w /app \
  --env-file .env \
  node \
  node index.js copy_schemas.js

3) For Local Docker Postgres

docker build -t pg_manage . --no-cache

docker run --rm --name pg_manage \
  --add-host=host.docker.internal:host-gateway \
  --env-file .env \
  pg_manage node index.js SME00445

docker run --rm --name pg_manage \
  --env-file .env \
  --add-host=host.docker.internal:host-gateway \
